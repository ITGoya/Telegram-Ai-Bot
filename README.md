# ربات تلگرام هوش مصنوعی \| Telegram AI Bot

یک ربات تلگرام مبتنی بر **Cloudflare Workers** و **Upstash Redis** برای
گفتگو با مدل‌های هوش مصنوعی، کمک در کدنویسی، دریافت فایل/تصویر و تولید
تصویر. مدیریت مدل‌ها و برخی تنظیمات نیز از طریق پنل ادمین داخل تلگرام
انجام می‌شود.

> **وضعیت پروژه:** کد از نظر نحوی با `node --check` بررسی شده است؛ با
> این حال، پیش از استفاده عمومی باید آن را در محیط خودتان با Telegram
> Bot API، Upstash و ارائه‌دهنده‌های مدل آزمایش کنید. سازگاری همه سرویس‌های
> API تضمین‌شده نیست.

## امکانات

-   گفتگوی متنی با مدل‌های سازگار با قالب **OpenAI Chat Completions
    API**.
-   انتخاب مدل چت از داخل ربات.
-   پشتیبانی اختیاری از مدل‌های دارای قابلیت بینایی (Vision) برای بررسی
    تصویرهای ارسالی.
-   تولید تصویر با APIهای سازگار با الگوی **Images Generations API**؛
    همچنین مسیر ویژه‌ای برای Pollinations در کد وجود دارد.
-   انتخاب مدل تصویر و مدیریت مدل‌های چت و تصویر از پنل ادمین.
-   افزودن، ویرایش و حذف مدل‌ها.
-   تاریخچه گفتگو و امکان ایجاد/انتخاب نشست گفتگو.
-   دکمه لغو درخواست در زمان پردازش مدل.
-   بررسی عضویت کاربر در کانال‌های اسپانسر تعریف‌شده.
-   آمار کاربران، مسدودسازی و رفع مسدودی از پنل مدیریت.
-   پشتیبانی از پاسخ‌گویی در گروه با فراخوانی ربات، منشن یا پاسخ به پیام
    خود ربات.
-   ذخیره تنظیمات و اطلاعات مورد نیاز در Upstash Redis.
-   اعتبارسنجی Secret هدر Webhook تلگرام پیش از پردازش درخواست.

## معماری و پیش‌نیازها

این پروژه به اجزای زیر نیاز دارد:

1.  **Telegram Bot** برای دریافت پیام‌ها و ارسال پاسخ.
2.  **Cloudflare Workers** برای اجرای کد جاوااسکریپت.
3.  **Upstash Redis** برای نگهداری مدل‌ها، نشست‌ها، تاریخچه و وضعیت‌های
    ربات.
4.  یک یا چند سرویس مدل هوش مصنوعی:
    -   سرویس چت با API سازگار با OpenAI Chat Completions؛
    -   سرویس تصویر با API سازگار با الگوی Images Generations، یا
        ارائه‌دهنده‌ای که مسیر ویژه آن در کد پشتیبانی شده باشد.

### فایل اصلی

-   `worker.js` --- کد Worker و منطق ربات.

اگر فایل شما نام دیگری دارد، هنگام بارگذاری در Cloudflare همان فایل را
به‌عنوان کد Worker قرار دهید یا نام آن را به `worker.js` تغییر دهید.

## ۱. ساخت ربات تلگرام

1.  در تلگرام وارد [@BotFather](https://t.me/BotFather) شوید.
2.  دستور `/newbot` را ارسال کنید.
3.  نام و username ربات را انتخاب کنید.
4.  توکن ربات را دریافت کنید و آن را محرمانه نگه دارید.
5.  شناسه عددی حساب تلگرام خود را به دست آورید؛ این مقدار برای
    `ADMIN_ID` استفاده می‌شود.

**توکن ربات را در کد، README، مخزن GitHub یا پیام عمومی قرار ندهید.**

## ۲. ساخت دیتابیس Upstash Redis

1.  وارد [Upstash](https://upstash.com/) شوید و یک دیتابیس Redis ایجاد
    کنید.
2.  بخش REST API دیتابیس را باز کنید.
3.  آدرس REST endpoint و توکن REST را بردارید.
4.  آن‌ها را در Cloudflare به‌صورت Secrets/Variables تنظیم کنید:
    -   `UPSTASH_URL` --- آدرس HTTPS مربوط به REST endpoint.
    -   `UPSTASH_TOKEN` --- توکن REST.

این پروژه از REST API مربوط به Upstash استفاده می‌کند؛ آدرس اتصال Redis
از نوع TCP به‌جای REST endpoint مناسب نیست.

## ۳. انتشار روی Cloudflare Workers

### روش پیشنهادی: داشبورد Cloudflare

1.  مخزن GitHub خود را بسازید و فایل `worker.js` و این `README.md` را در
    ریشه مخزن قرار دهید.
2.  وارد [Cloudflare Dashboard](https://dash.cloudflare.com/) شوید.
3.  به بخش **Workers & Pages** بروید.
4.  یک Worker جدید ایجاد کنید؛ در صورت استفاده از اتصال Git، مخزن GitHub
    را متصل کنید.
5.  محتوای `worker.js` را در ویرایشگر Worker قرار دهید یا تنظیمات Build
    را برای فایل پروژه خودتان انجام دهید.
6.  Worker را Deploy کنید.
7.  آدرس عمومی Worker را کپی کنید؛ معمولاً به شکل
    `https://<worker-name>.<account-subdomain>.workers.dev` است.

در این پروژه به‌صورت پیش‌فرض مسیر `GET /` پیام `Bot is active.` را
برمی‌گرداند. این فقط نشانه در دسترس بودن Worker است و به‌تنهایی اتصال کامل
ربات یا دیتابیس را اثبات نمی‌کند.

## ۴. تنظیم متغیرها و Secrets

در داشبورد Worker به **Settings → Variables and Secrets** بروید و موارد
زیر را اضافه کنید.

  ------------------------------------------------------------------------
  نام                      نوع پیشنهادی            توضیح
  ------------------------ ----------------------- -----------------------
  `BOT_TOKEN`              Secret                  توکن ربات تلگرام که از
                                                   BotFather گرفته‌اید.

  `ADMIN_ID`               Variable                شناسه عددی تلگرام ادمین
                                                   اصلی ربات.

  `UPSTASH_URL`            Secret یا Variable      آدرس HTTPS مربوط به
                                                   Upstash Redis REST API.

  `UPSTASH_TOKEN`          Secret                  توکن Upstash REST API.

  `WEBHOOK_SECRET_TOKEN`   Secret                  یک رمز تصادفی و امن .

  ------------------------------------------------------------------------

برای مقادیر محرمانه از **Secret** استفاده کنید. پس از افزودن یا تغییر
متغیرها، Worker را دوباره Deploy کنید, اگر داشبورد از شما خواست.

### ساخت Secret مربوط به Webhook

یک رشته تصادفی و محرمانه بسازید. برای سازگاری با Telegram Bot API از
حروف انگلیسی، عدد، `_` و `-` استفاده کنید و آن را در متغیر
`WEBHOOK_SECRET_TOKEN` ذخیره کنید. همین مقدار را در مرحله بعد هنگام ثبت
Webhook ارسال کنید.

**مهم:** اگر `WEBHOOK_SECRET_TOKEN` تنظیم نشده باشد، کد درخواست‌های POST
را با خطای `503` رد می‌کند. اگر Secret هدر با مقدار تنظیم‌شده یکسان نباشد،
درخواست با خطای `401` رد خواهد شد.

## ۵. تنظیم Webhook تلگرام

Webhook به تلگرام می‌گوید پیام‌های ربات را به آدرس Worker بفرستد.

در دستور زیر، مقادیر نمونه را با مقادیر واقعی خودتان جایگزین کنید. این
دستور را در ترمینال اجرا کنید؛ از قرار دادن توکن واقعی در اسکریپت‌های
عمومی یا مخزن GitHub خودداری کنید.

``` bash
curl -X POST "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook" \
  -d "url=https://<YOUR-WORKER-URL>/" \
  -d "secret_token=<WEBHOOK_SECRET_TOKEN>"
```
یا به این صورت
``` bash
https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=https://<YOUR_WORKER_NAME>.<YOUR_SUBDOMAIN>.workers.dev/
``` 

-   `<BOT_TOKEN>`: توکن واقعی ربات.
-   `<YOUR-WORKER-URL>`: دامنه کامل Worker، بدون علامت‌های `<` و `>`.
-   `<WEBHOOK_SECRET_TOKEN>`: دقیقاً همان مقداری که در Cloudflare به‌عنوان
    `WEBHOOK_SECRET_TOKEN` ذخیره کرده‌اید.

برای بررسی وضعیت Webhook:

``` bash
curl "https://api.telegram.org/bot<BOT_TOKEN>/getWebhookInfo"
```

پاسخ Telegram را بررسی کنید. در صورت مشاهده خطا، مقدار URL، Secret و
وضعیت Deploy را کنترل کنید.

برای حذف Webhook در صورت نیاز:

``` bash
curl "https://api.telegram.org/bot<BOT_TOKEN>/deleteWebhook"
```

پس از حذف، برای فعال شدن ربات باید دوباره `setWebhook` را اجرا کنید.

## ۶. راه‌اندازی مدل‌های هوش مصنوعی

مدل‌ها از داخل پنل ادمین ربات اضافه می‌شوند؛ بنابراین نیازی نیست API Key
مدل را در سورس کد قرار دهید.

### مدل چت

در تلگرام با حساب ادمین وارد ربات شوید:

1.  `/start` را بفرستید.
2.  پنل مدیریت را باز کنید.
3.  گزینه افزودن مدل چت را انتخاب کنید.
4.  اطلاعات درخواستی را وارد کنید:
    -   **نام نمایشی:** نامی که کاربران در منو می‌بینند.
    -   **Base URL:** آدرس پایه API سازگار با OpenAI.
    -   **API Key:** کلید ارائه‌دهنده.
    -   **Model Name:** شناسه دقیق مدل در ارائه‌دهنده.
    -   **Vision:** اگر مدل واقعاً تصویر را می‌پذیرد `yes` و در غیر این
        صورت `no`.

کد در زمان درخواست، در صورت نیاز مسیر `/chat/completions` را به Base URL
اضافه می‌کند. آدرس باید معتبر و مبتنی بر HTTPS باشد.

نمونه ساختاری (صرفاً نمونه، نه کلید یا سرویس تضمین‌شده):

``` text
Base URL: https://api.example.com/v1
Model Name: provider-model-id
API Key: YOUR_API_KEY
Vision: no
```

مقادیر واقعی Base URL و Model Name را از مستندات سرویس‌دهنده خود بردارید.
همه ارائه‌دهندگان، حتی اگر از قالب OpenAI استفاده کنند، الزاماً تمام
قابلیت‌ها یا پارامترها را پشتیبانی نمی‌کنند.

### مدل تصویر

از پنل مدیریت گزینه افزودن مدل تصویر را انتخاب کنید و موارد زیر را وارد
کنید:

-   نام نمایشی؛
-   Base URL مبتنی بر HTTPS؛
-   API Key (اگر سرویس کلید نمی‌خواهد، طبق راهنمای خود ربات مقدار `.` را
    وارد کنید)؛
-   شناسه مدل تصویر.

برای اکثر سرویس‌های سازگار، کد مسیر `/images/generations` را استفاده
می‌کند و درخواست تولید تصویر با اندازه `1024x1024` می‌فرستد. خروجی می‌تواند
URL تصویر یا داده Base64 باشد. در کد مسیر ویژه‌ای برای دامنه‌های
Pollinations نیز وجود دارد.

### نکات مهم اتصال API

-   قبل از افزودن مدل، مستندات ارائه‌دهنده را بررسی کنید.
-   آدرس پایه را همراه با مسیر اشتباه یا تکراری وارد نکنید؛ از الگوی
    Base URL مستندشده سرویس پیروی کنید.
-   کلیدهای API را در GitHub قرار ندهید.
-   برخی APIها در قالب OpenAI سازگار نیستند و ممکن است نیاز به تغییر کد
    داشته باشند.
-   سرویس تصویر ممکن است هزینه، محدودیت نرخ، سیاست محتوا یا محدودیت حجم
    خروجی داشته باشد.

## استفاده از ربات

1.  ربات را در تلگرام باز کنید و `/start` بفرستید.
2.  از منو، گفتگوی هوش مصنوعی یا تولید تصویر را انتخاب کنید.
3.  در صورت وجود چند مدل، مدل دلخواه را از منوی انتخاب مدل تعیین کنید.
4.  برای شروع یک مکالمه جداگانه از گزینه ایجاد گفتگوی جدید استفاده کنید.
5.  برای لغو درخواست در حال اجرا، اگر دکمه لغو نمایش داده شد از همان
    دکمه استفاده کنید.

### فایل و تصویر

کد تلاش می‌کند محتوای برخی فایل‌های متنی/کدنویسی با پسوندهای `.js`، `.py`،
`.txt`، `.json`، `.html`، `.css`، `.cpp` و `.java` را بخواند و به متن
درخواست اضافه کند. اندازه و نوع فایل همچنان تابع محدودیت‌های پیاده‌سازی و
Telegram Bot API است.

ارسال تصویر برای تحلیل به مدلی نیاز دارد که قابلیت Vision آن فعال شده و
واقعاً از ورودی تصویر پشتیبانی کند.

## دستورات گروه

ربات را به گروه اضافه کنید. رفتار پاسخ‌گویی به تنظیمات گروه و نحوه
فراخوانی بستگی دارد؛ ربات برای جلوگیری از پاسخ‌گویی بی‌مورد به هر پیام، هر
پیام عادی گروه را به‌عنوان درخواست در نظر نمی‌گیرد.

دستورات مدیریتی گروه که در کد تعریف شده‌اند:

  دستور           عملکرد
  --------------- ---------------------------------
  `/bot test`     بررسی پاسخ‌گویی ربات
  `/bot سکوت`     قراردادن ربات در حالت سکوت گروه
  `/bot صحبت`     فعال کردن پاسخ‌گویی ربات در گروه
  `/bot راهنما`   نمایش راهنمای مدیریت گروه

بخش تنظیمات و مدیریت اصلی از چت خصوصی ربات قابل استفاده است. دستورات
مدیریتی گروه برای ادمین‌های گروه و/یا ادمین اصلی مطابق منطق کد محدود
شده‌اند.

برای فراخوانی عمومی در گروه، ربات را منشن کنید، به پیام خود ربات پاسخ
دهید یا از پیشوند فراخوانی تعریف‌شده در کد استفاده کنید. رفتار دقیق ممکن
است با تنظیمات حریم خصوصی BotFather و مجوزهای ربات در گروه مرتبط باشد.

## عیب‌یابی

### ربات به پیام‌ها پاسخ نمی‌دهد

1.  بررسی کنید Worker در Cloudflare Deploy شده باشد.
2.  آدرس را با `getWebhookInfo` کنترل کنید.
3.  مطمئن شوید `WEBHOOK_SECRET_TOKEN` در Cloudflare و مقدار
    `secret_token` در Webhook دقیقاً یکسان هستند.
4.  مقدارهای `BOT_TOKEN` و `ADMIN_ID` را بررسی کنید.
5.  لاگ‌های Worker را در Cloudflare بررسی کنید.

### خطای `401 Unauthorized` در Worker

هدر Secret تلگرام با `WEBHOOK_SECRET_TOKEN` یکسان نیست. Webhook را با
Secret صحیح دوباره ثبت کنید.

### خطای `503 Webhook not configured`

متغیر محرمانه `WEBHOOK_SECRET_TOKEN` تنظیم نشده یا در محیط Deployشده در
دسترس نیست.

### خطای اتصال به Upstash

-   `UPSTASH_URL` باید REST endpoint دیتابیس باشد.
-   `UPSTASH_TOKEN` را بررسی کنید.
-   فعال بودن دیتابیس و محدودیت‌های شبکه/سرویس را بررسی کنید.
-   لاگ Worker را برای خطاهای Upstash ببینید.

### مدل چت پاسخ نمی‌دهد

-   API Key و شناسه مدل را بررسی کنید.
-   مطمئن شوید Base URL درست است و به HTTPS ختم می‌شود.
-   بررسی کنید ارائه‌دهنده از مسیر `/chat/completions` و قالب پیام‌های
    ارسالی پشتیبانی می‌کند.
-   در صورت خطای `401` یا `403` معمولاً کلید یا مجوزها مشکل دارند؛ در
    صورت `404` ممکن است URL یا شناسه مدل اشتباه باشد؛ در صورت `429` ممکن
    است محدودیت نرخ یا اعتبار حساب تمام شده باشد.

### تولید تصویر کار نمی‌کند

-   مطمئن شوید یک مدل تصویر در پنل ادمین ثبت و انتخاب شده باشد.
-   Base URL، API Key و Model Name را با مستندات ارائه‌دهنده تطبیق دهید.
-   بررسی کنید سرویس خروجی تصویری به‌صورت URL یا Base64 برگرداند.
-   به محدودیت زمان، حجم پاسخ، اعتبار API و محدودیت‌های Telegram توجه
    کنید.

### پنل مدیریت نمایش داده نمی‌شود

-   `ADMIN_ID` باید شناسه عددی حساب تلگرام ادمین باشد.
-   مطمئن شوید با همان حساب به ربات پیام داده‌اید.
-   پس از تغییر متغیرها Worker را Deploy مجدد کنید.

## امنیت

-   **هرگز** `BOT_TOKEN`، `UPSTASH_TOKEN`، کلیدهای مدل یا Secret مربوط
    به Webhook را در مخزن عمومی قرار ندهید.
-   اگر کلیدی به‌اشتباه منتشر شد، فوراً آن را از سرویس‌دهنده باطل و جایگزین
    کنید.
-   برای داده‌های محرمانه از Cloudflare Secrets استفاده کنید.
-   در صورت عمومی بودن مخزن، قبل از `git push` فایل‌ها و تاریخچه Git را
    برای وجود کلیدها بررسی کنید.
-   به ربات فقط مجوزهای تلگرامی موردنیاز را بدهید.
-   پیش از استفاده در مقیاس عمومی، هزینه و محدودیت نرخ APIها را کنترل
    کنید و آزمون‌های امنیتی/عملیاتی انجام دهید.
-   Secret مربوط به Webhook مانع دریافت درخواست‌های جعلی فاقد Secret
    معتبر می‌شود، اما جایگزین حفاظت از توکن‌ها، کنترل هزینه و پایش لاگ‌ها
    نیست.

## محدودیت‌ها

-   این پروژه برای اجرای روی Cloudflare Workers نوشته شده است و به
    تنظیمات محیطی آن وابسته است.
-   داده‌ها در Upstash Redis نگهداری می‌شوند؛ حذف یا تغییر دیتابیس می‌تواند
    تاریخچه و تنظیمات ذخیره‌شده را از بین ببرد.
-   پشتیبانی APIها وابسته به سازگاری واقعی ارائه‌دهنده با قالب درخواست‌های
    کد است.
-   بررسی نحوی جاوااسکریپت به معنی تضمین عملکرد کامل در محیط واقعی نیست.
-   برای استفاده عمومی یا تجاری، محدودیت‌های سرویس‌ها، هزینه‌ها، حریم
    خصوصی، قوانین تلگرام و شرایط استفاده ارائه‌دهندگان API را بررسی کنید.

## مشارکت

برای پیشنهاد قابلیت یا گزارش خطا، یک Issue در مخزن GitHub ایجاد کنید و
مراحل بازتولید خطا، پیام خطا و اطلاعات محیط را بنویسید. **توکن‌ها، API
Keyها، شناسه‌های حساس و اطلاعات شخصی را در Issue یا لاگ عمومی منتشر
نکنید.**

## مجوز

در حال حاضر مجوز رسمی در این مخزن مشخص نشده است. پیش از انتشار عمومی یا
استفاده مجدد از کد، مجوزی مانند MIT را فقط در صورتی اضافه کنید که حق
انتشار آن را دارید؛ در غیر این صورت وضعیت حقوقی کد را با صاحب اثر روشن
کنید.
